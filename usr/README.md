# Cleaning Post App

A cross-platform Flutter application designed as a simple job board or social feed for cleaning services. Users can view a feed of cleaning service offers or requests, see details like pricing and timing, and initiate contact.

## Features
- **Responsive Feed:** Displays a list of cleaning posts optimized for mobile, tablet, and desktop views.
- **Detailed Cards:** Each post includes the title, description, author, date, and price.
- **Interactive UI:** Includes action buttons to reply to posts and a floating action button to create new posts.

## Tech Stack
- Flutter
- Material 3 Design

## Running the App
1. Ensure Flutter is installed.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter run` to start the application.
